Project Summary

Over the years, the NAU CWC Team typically buy generators for competition. This project aims to develop a generator that can be modified by the CWC team. Our goal is to design modularized custom parts that can significantly decrease lead times compared to commerical parts and allow client preferences. Please view the Project Description page to learn more about this project.
